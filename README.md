## ✨ Что это

**Ролевая компашка** — это твоя личная песочница для ролевых чатов с нейросетями.
Никаких облаков, подписок и слежки. Модели крутятся локально через `llama.cpp`, переключаются на лету через `llama-swap`, а интерфейс — обычная веб-страница.

> 🎯 **Цель:** уютные ролевые вечера с нейронкой без интернета и без ограничений.

## 🎁 Возможности

<table>
<tr>
<td width="50%" valign="top">

### 🎭 Персонажи (NPC)
- Карточки с аватаром и фоном
- Характер для нейросети
- Подробное описание для тебя
- Вступительное сообщение

### 🌍 Миры
- Лор и история
- Законы и правила
- Идут в system-промпт
- Привязка к чату

### 👤 Игроки
- За кого ты играешь
- Описание уходит в промпт
- Свой аватар
- Много персонажей сразу

</td>
<td width="50%" valign="top">

### 🏘️ Группы
- Несколько NPC в одном чате
- Natural Order — отвечает тот, кого позвали
- Round-robin — если никто не упомянут
- Полоса участников с аватарами

### 💬 Чаты
- Множественные сессии
- Переключение на лету
- Превью последних сообщений
- Резюме истории в память

### 🎛 Настройки
- Все параметры генерации
- Серверные флаги (`n_ctx`, `n_gpu_layers`, `--flash-attn`)
- Фильтр мета-знаний
- Тёмная / светлая тема

</td>
</tr>
